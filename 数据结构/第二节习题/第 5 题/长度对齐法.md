# 长度对齐法

> 来源：ima 个人知识库 · 数据结构 · 第二节习题 · 第 5 题
> 导出时间：2026-10-07

## 思路

两个链表有公共结点时，从公共结点往后完全重合。先各求长度，让长链表的指针先走 `|lenA-lenB|` 步对齐起点，然后同步后移，第一次地址相等处即为公共结点。

## 代码

```c
// 求单链表长度
int getLen(LinkList L){
    LNode *p = L->next;
    int len = 0;
    while(p != NULL){
        len++;
        p = p->next;
    }
    return len;
}

LNode *findCommonNode(LinkList A, LinkList B){
    int lenA = getLen(A);
    int lenB = getLen(B);
    LNode *p = A->next, *q = B->next;

    // 长链表指针先走 |lenA-lenB| 步
    if(lenA > lenB){
        for(int i=0; i<lenA-lenB; i++)
            p = p->next;
    }else{
        for(int i=0; i<lenB-lenA; i++)
            q = q->next;
    }

    // 同步移动，直到地址相等
    while(p != NULL && q != NULL){
        if(p == q)
            return p;
        p = p->next;
        q = q->next;
    }
    return NULL; // 没有公共结点
}
```

## 复杂度

- 时间：O(lenA + lenB)，每条链表各扫两遍
- 空间：O(1)，只用两个指针
