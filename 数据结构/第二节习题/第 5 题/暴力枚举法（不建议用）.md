## 思路

双重循环：对 A 的每个结点，遍历 B 的所有结点比较地址是否相同。最直观但效率最差。

## 代码

```c
LNode *findCommonNode4(LinkList A, LinkList B){
    LNode *p = A->next;
    while(p != NULL){
        LNode *q = B->next;
        while(q != NULL){
            if(p == q)
                return p;
            q = q->next;
        }
        p = p->next;
    }
    return NULL;
```

## 复杂度

- 时间：O(lenA × lenB)，双层嵌套
- 空间：O(1)

## 为什么不推荐

只适合理解题意，实际做题/工程里用长度对齐法或双扫描指针法。
