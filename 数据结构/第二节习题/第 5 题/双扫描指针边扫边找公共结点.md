# 双扫描指针边扫边找公共结点

> 来源：ima 个人知识库 · 数据结构 · 第二节习题 · 第 5 题
> 导出时间：2026-10-07

## 思路

两个指针分别在两条链表上走，走到自己末尾就跳到对方链表的首元结点继续。因为「A 的尾 + B 的头」与「B 的尾 + A 的头」总长度相同，两指针必然在公共结点处（或同时在 NULL 处）相遇。不需要预先求长度。

## 代码

```c
LNode *findCommonNode2(LinkList A, LinkList B){
    LNode *p = A->next;
    LNode *q = B->next;

    while(p != q){
        // p走到A末尾，转到B的首元结点；否则继续后移
        p = (p == NULL) ? B->next : p->next;
        // q走到B末尾，转到A的首元结点；否则继续后移
        q = (q == NULL) ? A->next : q->next;
    }
    return p; // 有交点返回公共结点，无交点返回NULL
}
```

## 感悟（原笔记）

- 三元运算符只能用于简单的（if 和 else 函数体都只有一个表达式）if-else 语句
- 本题三元表达式是一个整体，通过赋值运算符赋值给 p、q 指针

## 复杂度

- 时间：O(lenA + lenB)
- 空间：O(1)
