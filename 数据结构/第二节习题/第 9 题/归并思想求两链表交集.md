# 归并思想求两链表交集

> 来源：ima 个人知识库 · 数据结构 · 第二节习题 · 第 9 题
> 导出时间：2026-10-07

## 前提

两条链表**已按 data 升序排列**（归并的前提）。结果复用 la 的头结点作为结果链表头，只保留两边都出现的元素，其余结点全部 `free` 掉。

## 代码

```c
typedef struct LNode{
    int data;
    struct LNode *next;
}LNode, *LinkList;

LinkList Intersect(LinkList &la, LinkList &lb)
{
    LNode *pa = la->next;   // pa指向A第一个数据结点
    LNode *pb = lb->next;   // pb指向B第一个数据结点
    LNode *pc = la;         // pc：结果链表尾指针，初始指向A的头结点
    LNode *u;               // u用来临时保存待释放结点

    while(pa && pb){
        if(pa->data == pb->data){
            // 两边都有该元素，保留pa，接入结果链表
            pc->next = pa;
            pc = pa;
            pa = pa->next;

            // pb的这个重复结点释放
            u = pb;
            pb = pb->next;
            free(u);
        }
        else if(pa->data < pb->data){
            // pa的值更小，B不存在该元素，直接删除pa
            u = pa;
            pa = pa->next;
            free(u);
        }
        else{   // pa->data > pb->data
            // pb的值更小，A不存在该元素，直接删除pb
            u = pb;
            pb = pb->next;
            free(u);
        }
    }

    // A剩下的结点，只存在A，不属于交集，全部释放
    while(pa){
        u = pa;
        pa = pa->next;
        free(u);
    }
    // B剩下的结点，只存在B，不属于交集，全部释放
    while(pb){
        u = pb;
        pb = pb->next;
        free(u);
    }

    pc->next = NULL;  // 结果链表尾置空
    free(lb);         // 释放B链表的头结点
    return la;        // 返回交集链表的头指针la
}
```

## 要点

- `pc` 是**尾指针**，始终指向结果链表最后一个结点，靠 `pc->next = pa; pc = pa;` 接龙
- 被淘汰的结点必须 `free`，否则内存泄漏
- 最后 `free(lb)` 释放第二个链表的头结点，两个链表合并成了一个
- 时间 O(lenA + lenB)，空间 O(1)
